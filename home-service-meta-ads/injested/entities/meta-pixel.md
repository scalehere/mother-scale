JavaScript tracking snippet installed on the advertiser's website to capture visitor actions (page views, form submissions, phone clicks). Post-iOS, the Pixel is paired with the **Meta Conversion API** — a server-to-server data feed — to recover the tracking signal Apple's opt-out broke. See [[Creative Beats Targeting]] for the broader algorithm pivot this drove.

[[Hook Agency]] treats Pixel + Conversion API setup as a non-negotiable. Hunsaker discusses the algorithm consequences of losing the data signal but does less hand-holding on Pixel install — likely because his recommended primary conversion event is the in-platform lead form, which fires natively without Pixel.
