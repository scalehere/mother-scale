# Campaign Setup Settings — Home Services Facebook Ads

Definitive settings reference synthesized across all sources. Follow this when launching any home service client campaign.

---

## Campaign Level

| Setting | Value | Notes |
|---|---|---|
| Objective | **Leads** | Not engagement, not traffic, not awareness |
| Budget type | **Campaign Budget Optimization (CBO)** | Set at campaign level, not ad set. Facebook allocates to best-performing ad. |
| Budget amount | $35–100/day to start | Scale once winning creative found |
| Campaign name | Client + vertical + date | E.g., "ABC HVAC - Owner Intro - Apr2026" |

---

## Ad Set Level

| Setting | Value | Notes |
|---|---|---|
| Conversion event | **Instant forms (leads)** | Every form submit trains the pixel |
| Performance goal | **Maximize number of leads** | Not "conversion leads" — similar outcome, more volume |
| Location | City/neighborhood only | Type city name. Shrink radius to city-only. |
| "Reach more people" checkbox | **OFF** | Unchecking prevents ads showing outside service area |
| Detailed targeting | **None** | Creative finds the audience. Interest targeting usually hurts. |
| Age | 25+ optional | Age data on FB is often inaccurate. Optional and low-impact. |
| Language | **Don't touch** | Creative in English naturally targets English speakers |
| Placements | **Advantage Plus** (leave on) | 90% spend goes to FB feed, IG reels, IG feed anyway |
| Start date | Leave as-is | Auto-populates |

---

## Ad Level

| Setting | Value | Notes |
|---|---|---|
| Multi-advertiser ads | **OFF** | Don't let your ad cluster with competitors |
| Advantage+ creative enhancements | **ALL OFF** | Text improvement, image animation, enhanced CTA, image generation — turn off every one. You need to know what's actually working. |
| CTA button | **Get Quote** | Outperforms: Book Now, Learn More, Get in Touch |
| Primary text | Ad copy (see [[concepts/ad-copy-framework]]) | |
| Headline | Action-oriented: "Get your [X] done" | |
| Description | Social proof: "X+ 5-star Google reviews" | |

## Location Targeting (Critical Detail)

### Approach 1 — Dimsey (Exclusion Pins)
1. Drop pin on your city center
2. Set radius to your service area
3. Add additional exclusion pins around the radius perimeter
- Prevents Facebook from showing to people just outside your area
- "Facebook sometimes shows outside advertised location — happens a lot"

### Approach 2 — Hunsaker (City-Only)
1. Type city name
2. Shrink to city boundaries ("current city only")
- Tighter = better brand building in small area
- Exposure effect requires concentration of spend in small geography

**Agency recommendation**: Start with city-only or tight radius. Exclude surrounding areas manually for premium markets. Avoid the default "+25 miles" radius Facebook pre-fills.

---

## What to Ignore / Turn Off

- Campaign score (meaningless algorithm metric)
- Flexible catalog (shows up for some accounts, ignore it)
- All creative enhancements in the ad level
- "Reach more people likely to respond" checkbox at ad set level
- Detailed interest/demographic targeting for local home services

---

## Budget Scaling Path

1. Start: $35–75/day
2. After winning creative found (3–5 days): $100/day
3. Scale: $150/day → $200/day
4. Once scaling: can expand from single neighborhood → full city → adjacent cities
