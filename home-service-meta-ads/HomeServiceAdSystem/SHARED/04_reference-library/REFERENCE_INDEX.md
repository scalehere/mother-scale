# Reference Library Index

Master index of all structural reference patterns banked from competitor ads. Lives in `/SHARED/04_reference-library/` and grows across every client engagement.

Each REF is a structural skeleton — competitor brand colors, copy, logos, and geography are stripped at conversion time. Only layout DNA remains.

---

## How to add a new REF

1. Screenshot a competitor ad you want to bank
2. Run through your image-to-JSON tool
3. Open Cowork, paste Agent 5 (Reference Library Manager) system prompt
4. Paste raw JSON output
5. Agent converts → saves as REF-XXX → updates this index

See `/SHARED/02_agents/Agent05_ReferenceLibraryManager.md` for the workflow.

## Family taxonomy

| Family | Code | Description |
|---|---|---|
| Social proof — review card on lifestyle | 1A | Full-bleed lifestyle bg, centered review card overlay, reviewer block + platform mark + 5 stars + body |
| Social proof — split layout worker + review | 1B | Vertical split: action photo left, review card right |
| Offer-driven — stack with feature list + form CTA | 2A | 60/40 split, headline + body + checkmark feature list + button |
| Offer-driven — offer tag on action background | 2B | Full-bleed action photo, upper-left offer tag with savings-cue icon, photo-inset proof row, contact bar |
| Founder authority | 3A | Founder cutout/portrait + brand-name background + diagonal accent (Canlar-style) |
| Educational / explainer | 3B | Halftone illustration + decorative accents + content-aesthetic (TIG-style) |
| Before/After transformation | 4A | Horizontal 50/50 split, identical viewpoint both halves, clear divider |

## Notes for librarians

- Never add a REF that's a structural near-duplicate of an existing entry — Agent 5 will refuse
- Never include competitor brand specifics in REF files (no colors, copy, logos, phones)
- Every REF should serve concepts in either Family 1 (proof) or Family 2 (offer), not both — pattern matters
- When a REF has been used 5+ times across clients, mark it as "battle-tested" in this index
