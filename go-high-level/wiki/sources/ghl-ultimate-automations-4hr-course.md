## Key Takeaways

**Interface features documented:**
- Automation list view: folder organization, smart lists, duplicate, move to sub-account, edit, delete
- Inside a workflow: Settings tab (reentry settings, time zone, default sender name/number, send window), Enrollment History (all contacts that ran through), Execution Logs (fire history with timestamps)
- Sidebar: Notes, Error Checker, Stats view, Sticky Notes, zoom controls

**Important insight: Contacts tab + Automations**
- You can view how automations performed *inside the contact record* — this is the only place in GHL where you can manually *run* an automation on a contact
- Understanding contacts and automations together is critical; they're deeply interwoven
