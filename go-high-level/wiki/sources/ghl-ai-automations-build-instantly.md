## Summary

A focused 8-minute deep-dive into the [[GHL AI Automation Builder]], demonstrating it against two specific non-template scenarios: a cold voicemail campaign with SMS/email follow-up, and a review request sequence with wait periods and repeats. Also covers the AI Assistant sidebar (8-panel panel inside the automation editor). Key message: the feature actually works well, unlike many GHL Labs features, and generates complete unique workflows in seconds.

## Key Takeaways

- **Enable via Labs:** If "Build using AI" button is missing, go to Settings → Labs and enable it.
- **Generates unique workflows, not just recipes:** The AI builds custom flows from plain prompts even when no matching template exists. Example: "cold voicemail campaign with SMS and email follow-up" — no such recipe existed, AI built it anyway.
- **Speed:** Workflow generation completes in seconds, not minutes.
- **Complex prompts work:** "Send review request on Email + SMS → wait 1 hour → repeat" — AI correctly built this multi-channel, time-delayed, repeating sequence.
- **AI Assistant sidebar (8 panels):** Inside the automation editor, the AI assistant can: (1) answer questions, (2) assist building, (3) add actions, (4) configure actions, (5) suggest next steps, (6) improve existing workflow, (7) describe current workflow, (8) link support articles.
- **Always test before going live:** Use "Test Workflow" button. AI-generated automations need configuration (e.g., uploading actual voicemail file) and testing.
- **Creator's honest assessment:** Most new GHL features barely work at launch. This one works well right away.
