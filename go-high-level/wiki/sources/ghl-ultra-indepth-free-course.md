## Key Takeaways

**Agency View vs Subaccount View:**
- **Agency view** = admin/management layer. Controls all subaccounts. Where you configure SaaS plans, rebilling, agency-level settings.
- **Subaccount view** = the business layer. Where you build websites, send messages, run automations, manage CRM. This is where most day-to-day work happens.
- Switcher: search and pin subaccounts. Pinning is critical when managing many clients.
- The $497/month plan unlocks the SaaS Configurator — the key differentiator for agencies wanting to resell GHL.

**Agency Dashboard:**
- Shows total revenue, MRR, new customers, total customers, growth charts
- Rebilling tab: shows per-subaccount markup earnings across phone, email, WhatsApp, AI products

**SaaS Configurator (497 plan only):**
- Auto-provisions subaccounts when a client pays — no manual setup needed
- Create tiered SaaS plans: name, description, price (monthly + optional annual), user/contact limits, feature access list, optional snapshot injection, optional custom menu links, optional free trial period, optional wallet credits
- Payment processors: Stripe, NMI, Authorize.net, Square
- Advanced: pause subaccount on failed payment, allow client self-upgrade, allow client self-cancel, customizable welcome email, 2FA requirement
- Category system for plan organization (e.g., SaaS for Plumbers, SaaS for HVAC)
- Generate a sale link from the plan → send directly to client → they pay → subaccount auto-created

**Rebilling (agency revenue model):**
- GHL charges the agency for usage (SMS, email, WhatsApp, AI, phone)
- Agency can mark up the rate charged to subaccounts (e.g., pay $0.009/SMS, charge client $0.010/SMS)
- Transparent rebilling best practice: tell clients upfront about usage costs
- At scale (hundreds of clients), small markups add up significantly

**Subaccount Management:**
- Search, filter, timestamp view
- Duplicate automations/snapshots across subaccounts
- Transfer subaccounts between agencies
