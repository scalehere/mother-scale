The most comprehensive trigger and action reference in the wiki. Published February 2026 — the most current source. Covers every trigger category (Contact, Events, Appointments, Opportunities, Affiliates, Courses, Payments, E-commerce, IVR, Social, Communities, Certificates, Google Ads) and every action category (Contact, Custom Objects, Communication, Send Data, Internal Logic, AI, Appointments, Opportunities, Payments, Marketing, Affiliates, Memberships, IVR, Agent Studio, Communities, Conversation AI, Voice). Also covers the automation sidebar (notes, error checker) and a live workflow build demo.

## Key Takeaways

**Architecture:**
- Three ways to build: scratch, templates, AI builder
- Always name the workflow first
- Most of the automation = actions (the bulk). Triggers are just the start.
- Automations are last to learn in GHL — they automate *other* GHL features, not standalone things. Learn the features first, then automate them.

**Complete Trigger Categories:**
- **Contact:** birthday reminder, contact changed/created/DND, tag added/removed, custom date reminder, note added/changed, task added/reminder/completed, engagement score
- **Events:** webhooks, scheduler, call status, email events, customer replied, conversational AI trigger, custom trigger, form/survey submitted, trigger link clicked, Facebook lead form, TikTok form, video tracking, number validation, messaging error, LinkedIn lead, funnel/website page view, quiz submitted, new review, prospect generated, Click-to-WhatsApp ads, internal tracking event
- **Appointments:** appointment status, show/no-show, customer booked, service booking, rental booking
- **Opportunities:** status changed, created, pipeline stage changed, stale opportunities
- **Affiliates:** affiliate created, new affiliate sale, enrolled in campaign, lead created
- **Courses:** category/lesson started/completed, new signup, offer granted/removed, product access, user login
- **Payments:** invoice event, payment received, order form submission, documents/contracts, estimates, subscription, refund, coupon events
- **E-commerce:** Shopify abandoned cart (being deprecated), order placed/fulfilled, product review, abandoned checkout
- **IVR:** IVR start trigger
- **Social (FB/IG):** comment on post, DM triggers
- **Communities:** group access granted/revoked, private channel access, leaderboard
- **Certificates:** certificate trigger
- **Google Ads:** Google Ads trigger

**Complete Action Categories:**
- **Contact:** create, find, update field, add/remove tag, assign/remove user, enable/disable DND, add notes, copy, edit conversation, add task, delete contact, modify engagement score, add/remove followers
- **Custom Objects:** create/update/clear associated records, add/remove from workflow
- **Communication (heavy hitters):** send email, SMS, Slack, call, voicemail, Messenger, Instagram DM, manual SMS/call action, internal notification, send review request, conversational AI, Facebook/Instagram reply to comments, WhatsApp (service, send flows, live chat, media, interactive), appointment booking conversation AI, TikTok interactive messenger
- **Send Data (premium/advanced):** Zapier webhook, custom webhook, Google Sheets
- **Internal Logic:** if/else branching, wait steps, goal event, split test, update custom value, go-to, date/time, formatter, math operations, lead scoring, set events, start date, add/remove from workflow, array functions, drip text, custom code
- **AI (external):** ChatGPT integration (legacy, mostly superseded by native AI)
- **Appointments:** update status, create appointment, booking note, generate one-time booking link
- **Opportunities:** create/update/remove opportunity, add/remove owner, add/remove followers, find opportunity
- **Payments:** Stripe one-time charge, send invoice/estimate/documents/contract/recurring invoice
- **Marketing:** Add to Google Analytics/Ads, Facebook Custom Audience add/remove, Meta Conversation API, generate marketing audit report
- **Affiliates:** add to manager, update, add/remove from campaign, add leads under affiliate, manual affiliate sales
- **Memberships/Courses:** grant/revoke course offer
- **IVR:** gather input, play message, contact call, call record, voicemail
- **Agent Studio:** AI translate, AI summarize, AI intent detection, AI decision maker
- **Communities:** smart push notification, grant/revoke group access, private channel access, leaderboard points
- **Conversation AI (chatbot):** AI capture info, AI book appointment, AI splitter, AI message, custom message, transfer bot, continue conversation
- **Voice (inbound AI):** AI voice agent call

**Premium actions:** marked with crown icon — require extra payment, mostly third-party integrations.

**Sidebar features:** Notes (leave instructions for self/team), Error Checker (red indicator if workflow has issues like missing from-email).

**Live demo built:** Form submitted → send email → wait 35 min → send SMS
