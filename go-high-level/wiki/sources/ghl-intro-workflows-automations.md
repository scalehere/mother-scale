## Summary

GHL's official introductory workflow automation article. Covers the core definition, five key business benefits, four primary use cases, step-by-step setup guide with screenshots, and an important FAQ answer on how to manually add a contact to a workflow.

## Key Takeaways

**Five key benefits of workflow automation:**
1. **Increased Efficiency** — free team for strategic priorities
2. **Improved Accuracy** — eliminate manual errors
3. **Cost Savings** — reduce labor dependency
4. **Enhanced Customer Experience** — faster response to interactions
5. **Scalability** — handle higher workloads without adding resources

**Official use case categories:**
1. Lead management (auto-capture → CRM update → welcome email)
2. Appointment scheduling (confirmations + reminders)
3. Customer support (ticket assignment, team notifications)
4. Marketing campaigns (personalized follow-ups triggered by link clicks or email opens)

**How to manually add a contact to a workflow:**
> Open the contact → click **Automation** tab → **Add Workflow** → choose the workflow → set start time → click **Add**

This is the only place in GHL where you can manually trigger a workflow on a specific contact — not available from the workflow builder itself. (Consistent with what the 4-hour course noted.)

**Three workflow creation paths:**
1. Start from scratch
2. Select from Recipe (pre-built templates)
3. Select from Template (template library)
