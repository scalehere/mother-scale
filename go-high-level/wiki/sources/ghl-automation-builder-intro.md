## Summary

A 13-minute tutorial walking through the three automation builders inside GoHighLevel: the Basic builder (single trigger → actions), the Advanced builder (drag-and-drop canvas, multiple triggers), and the AI builder (natural language → full automation including copy). The core thesis is that these must be learned in order — AI amplifies existing knowledge but cannot replace foundational understanding.

## Key Takeaways

- **Every automation = trigger + actions.** The trigger is the opening event (form submitted, contact created, etc.); actions are everything that follows (email, SMS, wait, webhook, etc.).
- **Basic builder**: Linear, single-trigger workflow. Best for learning the mental model. Limited to one trigger per workflow.
- **Advanced builder** (in Labs): Drag-and-drop canvas, multiple triggers, keyboard shortcuts. Enables multiple automations within one flow. Analogous to n8n-style visual builders.
- **AI builder**: Describe desired automation in natural language → GHL generates triggers, actions, and all copy (emails, SMS). Can iterate: "change all emails to SMS" reruns generation. Powerful only if you understand what it builds.
- **Learning order matters:** Basic → Advanced → AI. Skipping to AI without foundation leads to poor-quality automations and underestimating what the tool can do.
- **Business value framing:** Automations save businesses time = make them money. Core selling proposition for GHL agencies.
- **Pro tip:** Set default sender name/number in workflow settings to avoid re-entering it manually each time.
