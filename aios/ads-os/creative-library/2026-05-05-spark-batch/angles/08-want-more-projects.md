# Angle 08 — "Want More Projects?"

> Source: Spark ads 2006772290049397, 973556245393379, 2036598270537928 ("Want More Projects From Your Ads?")
> Pattern: direct want-question. Lowest-creativity angle but it works because it names the outcome contractors search for.

## Original (Spark)

"Remodelers, Want More Projects From Your Ads?"

## Default rewrite — GC, EN, 15s, Peter on-camera

**[Hook]**
"San Diego contractors. Want more jobs on the calendar before summer hits?"

**[Body]**
"We film, we run the ads, we manage the leads."

**[Offer]**
"90 exclusive leads in 12 weeks. Yours alone."

**[CTA]**
"Tap below."
