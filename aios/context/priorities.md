The 90-day priorities. If these aren't done by end of June, Q2 was wasted.

## 1. Build the AIOS that automates fulfillment

Per the 2026-05-04 strategic decision, this is the binding priority. Build skills that mirror the offer ladder so each one is both an internal time-saver and a productizable client-facing snapshot.

**Updated 2026-05-04 evening:** social-organic ships first (sub-OS scaffolded at `social-os/`) because all 4 active clients pay for it and the recurring time bleed is biggest. Website-build moves to second-half of the quarter once a new Foundation client triggers it.

**The social-os skill ladder (one per week via `/level-up`):**

1. **`client-strategy-session`** — automate the Month-1 client intake (voice, pillars, audience, platforms, competitors, offers, shot wishlist)
2. **`brand-voice-profile`** — extract a client's voice from past posts into a config doc
3. **`monthly-content-plan`** — generate the next month's full calendar mapped to the 5 pillars
4. **`shot-list`** — 20-item shot list 1 week before the monthly shoot
5. **`caption-writer`** — per-post platform-specific captions in client voice
6. **`reel-script`** — 30-60s Reel script in client voice from a content-pillar topic
7. **`post-scheduler`** — load approved posts into the scheduling tool of record
8. **`weekly-engagement-digest`** — DMs/comments/mentions across platforms triaged
9. **`monthly-client-report`** — performance + insights + next-month preview

**Then** (Q3 2026 or as triggered by client need):
- Website-build skill (Foundation tier — when next Foundation client onboards)
- GBP + Yelp setup skill (Foundation tier)
- Paid-ads campaign skill (Scale tier — Meta Ads MCP + Higgsfield)
- GHL automation snapshot skill (= the CRM Add-On product)

Cadence: one shipped skill per week via the `/level-up` ritual.
